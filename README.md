## 更新日志

### v1.4（2026-11-26）
- 电脑端加了键盘快捷键（只在电脑端显示说明）：空格听发音，C 查看中文释义，1 判不会/错误、2 判正确，Enter 下一个，B 打开错题本，S 分享卡片，Esc 回到主界面；拼写模式里 Enter 提交、再按一次就是下一个，1 是不知道
- V 键切换英式/美式发音，X 键显示当前卡片模糊的音标（显示后这张卡一直可见，换下一张重新遮起）
- 拼写模式里点了输入框、正在输入单词的时候，按空格就是输入空格，不听发音；鼠标点在输入框以外、没在输入单词的时候，按空格还是听发音
- 两版再次全面对过，除了词库不同，其他功能完全一致
